# Pixel Ciempies WebVR

Build WebXR de **Pixel Ciempies VR** para probar en Meta Quest Browser.

- Sitio: https://odsanchezuniversitaria-web.github.io/pixel-ciempies-webvr/
- Pulsa **VR** después de que termine la carga.
- GitHub Pages sirve el sitio por HTTPS, requisito de WebXR.

La variante WebXR permite jugar en realidad virtual desde el navegador. Las funciones nativas de realidad mixta/OpenXR del APK no están disponibles en WebGL.
